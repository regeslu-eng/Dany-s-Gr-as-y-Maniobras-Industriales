## Publicar en GitHub / Vercel

1. Reemplaza en tu repositorio los archivos por los de esta carpeta.
2. Conserva la carpeta `assets/`.
3. Haz commit y push a GitHub.
4. Vercel debe hacer el nuevo deployment automáticamente.
5. Comprueba en el navegador:
   - `https://www.gruasdanysqueretaro.com/`
   - `https://www.gruasdanysqueretaro.com/robots.txt`
   - `https://www.gruasdanysqueretaro.com/sitemap.xml`

## Google Search Console

Después de que Vercel termine de publicar:

1. Regresa a Search Console.
2. En la ventana de **Verifica la propiedad**, pulsa **VERIFICAR**.
3. Ve a **Sitemaps** y escribe `sitemap.xml`.
4. En **Inspección de URL**, inspecciona `https://www.gruasdanysqueretaro.com/`.
5. Pulsa **Solicitar indexación**.

La verificación confirma la propiedad. La indexación puede tardar; no significa que Google vaya a mostrar la página de inmediato para todas las búsquedas.
